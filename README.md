
# Web Bán Giày Minh Luân Store

## 1. Giới thiệu dự án

MINHLUAN-STORE là dự án website bán giày nam được xây dựng
trong quá trình học tập và thực hành phát triển web.
Dự án giúp vận dụng kiến thức xây dựng giao diện website,
tổ chức mã nguồn và quản lý phiên bản bằng Git, GitHub.

## 2. Công nghệ sử dụng

- HTML: xây dựng cấu trúc các trang web.
- CSS: định dạng giao diện và bố cục.
- JavaScript: xử lý các thao tác tương tác trên website.
- Git: quản lý lịch sử thay đổi của mã nguồn.
- GitHub: lưu trữ và chia sẻ Repository trực tuyến.

## 3. Cấu trúc dự án

- `index.html`: trang chủ.
- `giaynam.html`: trang giày nam.
- `giohang.html`: trang giỏ hàng.
- `blog.html`: trang blog.
- `lienhe.html`: trang liên hệ.
- `css/`: chứa các tệp định dạng giao diện.
- `js/`: chứa các tệp JavaScript.
- `img/`: chứa tài nguyên hình ảnh.
- `lab/`: chứa các bài thực hành.

## 4. Cách chạy dự án

1. Clone Repository về máy tính.
2. Mở thư mục dự án bằng Visual Studio Code.
3. Mở file `index.html` bằng trình duyệt web để xem giao diện.

## 5. Quản lý mã nguồn

Dự án được quản lý bằng Git và lưu trữ trên GitHub.
Các thay đổi được ghi nhận thông qua commit và đồng bộ
với Repository từ xa bằng lệnh push.
